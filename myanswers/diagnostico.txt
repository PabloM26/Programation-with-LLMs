================================================================
DIAGNÓSTICO - answer-0204: optimizar_bosque_aleatorio
================================================================

TIPO: Incompatibilidad entre el formato de retorno del generador
      y la lógica de comparación del validador.

----------------------------------------------------------------
DESCRIPCIÓN DEL PROBLEMA
----------------------------------------------------------------

El validador reporta el siguiente mismatch:

  "Caso de uso: Optimización de hiperparámetros con Random Search"
  != {'mejores_parametros': {'n_estimators': 100, 'max_depth': 20}}

El lado izquierdo es un string descriptivo. El lado derecho es
el dict que retorna la función del estudiante. Que el validador
compare un string contra un dict indica que está tomando el
elemento equivocado del generador como "expected output".

----------------------------------------------------------------
ANÁLISIS DEL GENERADOR 
----------------------------------------------------------------

El generador tiene el siguiente formato de retorno:

    caso_dict = {
        "input":  {"X": X, "y": y},
        "output": {"mejores_parametros": search.best_params_}
    }
    return caso_dict, "Caso de uso: Optimización de hiperparámetros
                       con Random Search"

Retorna una tupla de dos elementos:
  - Elemento [0]: caso_dict, un dict que contiene tanto el input
                  como el expected output anidados bajo sus claves
  - Elemento [1]: un string meramente descriptivo del caso de uso,
                  sin valor de comparación

----------------------------------------------------------------
SITUACIÓN DEL CASO
----------------------------------------------------------------

Al revisar el generador de question-0004:
    input, expected = generador()
    # input   = caso_dict  (el dict completo, NO solo los datos)
    # expected = "Caso de uso: ..."  (el string, NO el output real)

El validador compara student_output contra el string descriptivo,
lo que produce siempre un mismatch independientemente de si es
correcta la función diseñada.

----------------------------------------------------------------
EVIDENCIA DE CORRECCIÓN DE LA SOLUCIÓN
----------------------------------------------------------------

La función implementada produce:
    {'mejores_parametros': {'n_estimators': 100, 'max_depth': 20}}

Este valor coincide exactamente con caso_dict["output"] del
generador:
    {"mejores_parametros": search.best_params_}

Donde search.best_params_ con random_state=42, n_iter=3, cv=3
y param_distributions = {'n_estimators': [50, 100, 200],
'max_depth': [None, 10, 20]} produce de forma determinista
{'n_estimators': 100, 'max_depth': 20}.

La función del estudiante es correcta. El error proviene
exclusivamente de que el validador no maneja el formato
particular del generador de question-0004, que difiere del
formato estándar en las demás preguntas.

----------------------------------------------------------------
CONCLUSIÓN
----------------------------------------------------------------

No se puede resolver este error porque:

1. El formato del generador (question-0004) es responsabilidad
   del compañero que creó esa pregunta.

2. El validador no contempla el formato de retorno que usa
   question-0004.

3. La función implementada produce el resultado correcto, como
   se puede verificar comparando su output con caso_dict["output"]
   del generador.
